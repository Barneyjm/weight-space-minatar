**Design.** The player never moves horizontally (it stays at column 5, the safest spot), so only row choice matters. Each row holds at most one entity (one slot per row), and an entity crosses the whole row, so gold in my row will reach me if I wait, and an enemy will hit me unless it has already passed column 5.

Layer 1 (24 of 32 units, all linear row features):
- units 0–7: "player in row r" (±1).
- units 8–15: danger in row r = tanh(0.4·score − 1), with score = f(enemy column) + g(trail column). f = [1,2,4,6,9,11,9,6,4,2], g = [0,−1,−2,−4,−6,−9,−6,−4,−2,−1] are solved so the sum equals 6 − distance for an enemy approaching column 5 and 0 for a departing one (trail gives the direction). Gold's trail only pushes this unit further negative (harmless).
- units 16–23: gold in row r, same trick with f = [3,3,6,6,9,9,9,6,6,3], g = [0,−3,−3,−6,−6,−9,−6,−6,−3,−3]: +0.9 if gold is approaching, −0.9 otherwise.

Layer 2 (22 units), each gated by the player-row unit (weight 6, bias −6, so off-row units sit at −1 and cancel through the output bias):
- STAY_r: −2·danger(r) + 1.5·gold(r).
- UP_r: danger(r) − 1.5·danger(r−1) + 1.2·gold(r−1) + 0.6·gold(r−2) + 0.3·gold(r−3).
- DOWN_r: mirror image. Small centering bonus at the edge rows.

Output: noop = 10·STAY + 4 (margin so the agent sits still), up = 10·UP, down = 10·DOWN, left/right/fire ≈ −12. Result: leave a row as soon as an enemy approaches, into the safer neighbour (departing enemies count as safe, so it dodges back and forth), step toward approaching gold up to three rows away, and sit on gold rows until the pickup.
